# Titanic Exploratory Data Analysis and Visualization

## Project Overview
Exploratory Data Analysis of the Titanic dataset using Python.

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Data Loading
- Data Cleaning
- Missing Value Analysis
- Statistical Analysis
- Data Visualization
- Correlation Analysis
- Outlier Detection
- Feature Engineering

## Key Insights
- Survival analysis
- Gender-wise survival
- Passenger class-wise survival
- Age distribution
- Fare analysis
